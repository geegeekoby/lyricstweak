Adding it by hand

  1. Sileo — Sources, then the + button, then paste the address.
  2. Zebra — Sources, then Add Source, then paste the address.
  3. Anything else — the repository is a plain APT repository, so deb — ./ in a sources list works too.

Then find LyricsTweak under Tweaks and install it. Nothing outside the tweak's own preferences is touched, and the lyrics library is opt-in from the same screen.

What the repository serves

  • /Packages and /Packages.gz — the index every package manager reads first.
  • /Release — the repository's own description. Unsigned: there is no private key kept here to sign it with, and the package's bytes are verified against the hash in the index regardless.
  • /debs/<file> — the .deb itself, served from the same bytes that were measured for the index. It is not committed to the source repository.
  • /depiction/<package> — the page Sileo shows before you install, and /depiction/<package>.json for Sileo's native rendering of it.
  • /repo/manifest — the same index as JSON, which is what the current build shown above is read from.

Building it yourself

The same .deb is built by GitHub Actions on every push, on a macOS runner with Theos and the iOS 16.5 SDK, published to this repository from there, and additionally attached to a GitHub release when a version tag is pushed. Locally, with Theos installed, it is make package FINALPACKAGE=1 THEOS_PACKAGE_SCHEME=rootless.

The lyrics library · runs on Netlify Functions and Netlify Database.
